## 索引恢复与数据边界

每次索引更新前，将已验证的上一份索引原子写入 `index.json.bak`。主索引损坏或缺失时，仅从有效备份恢复，并关闭所有工作区模型授权；界面显示恢复提示和重新授权入口。备份可能早于最近操作，且不包含知识正文。

没有有效备份而存在知识文件、损坏索引或其他存储痕迹时，明确报错并保留原文件，不会创建空库。普通 I/O 错误同样不会触发重置。若初始化已失败，恢复有效索引后需要重启 Harness。

这不是完整版本历史：正文与索引仍是分别写入的文件，索引备份无法回滚正文。请将完整数据目录备份、来源快照、正文 revision 与一致性恢复作为后续存储阶段处理。

## 后续产品阶段

按顺序推进：来源 hash 与增量更新 → 正文版本及人工修改保护 → 持久生成任务 → chunk 引用和新鲜度 → 经验候选、反馈与固定评测集。宽屏列表/详情双栏与完整 Markdown 语义可在独立 UI 阶段验证。

本轮没有增加向量服务、训练任务或更新模型权重。PDF 回退解析仍是受限实现：冲突字体映射会明确报错，复杂 PDF 建议使用 pdftotext，扫描件仍需 OCR。
